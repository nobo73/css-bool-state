実用例4: アプリケーションレイアウト :checked

  • ダッシュボード

  • 設定

メインコンテンツ

サイドバーの表示/非表示をCSSのBool値で制御しています。 モーダルダイアログも同様にBool値で管理されています。

情報

これはCSSだけで実装されたモーダルダイアログです。

JavaScriptは一切使用していません。

確認

この操作を実行してもよろしいですか？

/* サイドバーの表示/非表示 */
#sidebar-toggle:not(:checked) ~ .app-layout .sidebar {
  width: 0;
  padding: 0;
}

/* モーダルの表示 */
.modal-trigger input:checked ~ .modal-overlay {
  display: block;
}

各手法の特性を理解し、適切に組み合わせることで、 パフォーマンスが高く、アクセシビリティに優れたWebアプリケーションを構築できます。
