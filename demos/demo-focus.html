🎯 CSS Bool値管理: :focus-within 疑似クラス

フォーカス状態を使用したBool値の保存・変更・参照

💡 :focus-within疑似クラスの特徴:
• 要素自身または子孫要素にフォーカスがある時にマッチ
• ユーザーインタラクション中のみ有効（一時的なBool値）
• アクセシビリティに優れた実装が可能
• キーボードナビゲーションに対応
⚠️ 制限事項:
• フォーカスが外れると状態が失われる（永続的な保存には不向き）
• フォーカス可能な要素（input, button, aなど）が必要
• セッション全体での状態保持には:checkedや:targetの方が適している

例1: ドロップダウンメニュー（フォーカスベースのBool値）

ボタンやメニュー項目にフォーカスがある間、メニューを表示します。 Bool値 = フォーカスの有無
オプション 1 オプション 2 オプション 3 オプション 4
/* フォーカスが内部にある時（Bool値 = true） */
.dropdown:focus-within .dropdown-menu {
  opacity: 1;
  visibility: visible;
}

例2: 検索ボックス（拡張型）

検索ボックスにフォーカスすると、ボックスが拡張され、候補が表示されます。
検索候補 1
検索候補 2
検索候補 3
検索候補 4
/* フォーカス時に検索ボックスを拡張 */
.search-container:focus-within .search-box {
  width: 500px;
}

/* 候補を表示 */
.search-container:focus-within .search-suggestions {
  max-height: 300px;
}

🎯 :focus-withinの使用場面:
• ドロップダウンメニュー、サブメニュー
• 検索ボックスの拡張と候補表示
• フォームセクションのハイライト
• カードやパネルの展開
• ツールチップの表示
• チャットやコメント入力エリアのアクティブ状態

注意: 永続的な状態保存が必要な場合は、:checkedや:targetを使用してください。
