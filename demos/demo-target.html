🎯 CSS Bool値管理: :target 疑似クラス

URLハッシュを使用したBool値の保存・変更・参照

💡 :target疑似クラスの特徴:
• URLのハッシュ（#id）を使用して状態を管理
• ブラウザの戻る/進むボタンで履歴管理が可能
• ページをリロードしても状態が保持される（URLに含まれるため）
• ブックマークやリンク共有で特定の状態を共有可能

例1: シンプルなBool値トグル

URLハッシュを使用して、Bool値のtrue/falseを切り替えます。 ブラウザの戻るボタンで前の状態に戻ることができます。
Bool値をTRUEに設定 Bool値をFALSEに設定
現在のURL: ...#state-true
現在のURL: ...#state-false (またはハッシュなし)
/* Bool値がtrueの時（URLに#state-trueが含まれる時） */
#state-true:target {
  display: block;
}

/* Bool値がfalseの時は他の要素を非表示に */
#state-true:target ~ #state-false {
  display: none;
}

例2: モーダルダイアログ（URLベースのBool値）

URLハッシュを使用してモーダルの表示/非表示を制御します。 モーダルを開いた状態でURLを共有できます。
モーダル1を開く モーダル2を開く モーダル3を開く

モーダル1

このモーダルは #modal1 がURLに含まれる時に表示されます。

Bool値 = true の状態です。

閉じる（Bool値をfalseに）

モーダル2

URLハッシュを使用することで、複数の独立したBool値を管理できます。

このモーダルのBool値 = true

閉じる

モーダル3

ブラウザの戻るボタンでモーダルを閉じることもできます。

これはネイティブなブラウザ機能です。

閉じる
/* モーダルのBool値がtrueの時 */
.modal:target {
  display: flex;
}

例3: タブUI（URLハッシュで状態管理）

各タブの状態をURLで管理します。特定のタブを開いた状態でリンクを共有できます。

タブ1のコンテンツ

URLに #tab-panel1 が含まれる時、このタブのBool値 = true

他のタブのBool値は自動的にfalseになります。

タブ2のコンテンツ

URLベースの状態管理により、ページをリロードしても選択されたタブが保持されます。

タブ3のコンテンツ

ブラウザの履歴機能を使用して、タブの切り替え履歴を辿ることができます。

タブ1 タブ2 タブ3
/* 対応するタブがターゲットの時に表示 */
.tab-panel:target {
  display: block;
}

例4: アコーディオン（複数の独立したBool値）

各セクションが独立したBool値を持ち、URLで状態を管理します。
セクション1（クリックして開く）
このセクションのBool値がtrueの時に表示されます。 URLに #acc-target1 が含まれます。
セクション2（クリックして開く）
:target疑似クラスを使用すると、一度に1つのセクションのみを開くことができます。 これは排他的なBool値管理に適しています。
セクション3（クリックして開く）
複数のセクションを同時に開きたい場合は、:checked疑似クラスの方が適しています。
/* ターゲットされた時にコンテンツを表示 */
.accordion-target-item:target .accordion-target-content {
  max-height: 500px;
}
