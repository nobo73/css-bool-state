🎯 CSS Bool値管理: :checked 疑似クラス

チェックボックスとラジオボタンを使用したBool値の保存・変更・参照

例1: トグルスイッチ（基本的なBool値）

最もシンプルなBool値の実装。チェックボックスの状態（checked/unchecked）を Bool値（true/false）として扱います。
/* Bool値がtrueの時のスタイル */
input[type="checkbox"]:checked + label {
  background: #4CAF50;
}

/* Bool値を参照して他の要素を制御 */
input[type="checkbox"]:checked ~ .status-display {
  background: #e8f5e9;
  color: #2e7d32;
}

例2: タブUI（複数のBool値管理）

ラジオボタンを使用して、複数のBool値のうち1つだけをtrueにする排他的な状態管理。 タブUIの実装に最適です。

タブ1のコンテンツ

Bool1 = true の時に表示されます。他のBool値は自動的にfalseになります。

タブ2のコンテンツ

Bool2 = true の時に表示されます。ラジオボタンの特性により、排他的な状態管理が可能です。

タブ3のコンテンツ

Bool3 = true の時に表示されます。JavaScriptなしで実装できます。

/* 特定のラジオボタンがtrueの時にコンテンツを表示 */
#tab1:checked ~ .tab-contents #content1 {
  display: block;
}

例3: アコーディオン（複数の独立したBool値）

各項目が独立したBool値を持ち、複数の項目を同時に開くことができます。
このセクションのBool値がtrueの時に表示されます。 他のセクションとは独立して開閉できます。
各セクションは独立したBool値を持っているため、 複数のセクションを同時に開くことができます。
CSSのmax-heightとtransitionを使用して、 スムーズなアニメーションを実現しています。
/* Bool値がtrueの時にコンテンツを表示 */
.accordion-item input:checked ~ .accordion-content {
  max-height: 500px;
}

例4: モーダルダイアログ（Bool値で表示制御）

Bool値を使用してモーダルの表示/非表示を制御します。

モーダルダイアログ

Bool値がtrueの時に表示されます。

このモーダルはCSSだけで実装されており、JavaScriptは使用していません。

/* Bool値がtrueの時にモーダルを表示 */
input:checked ~ .modal-overlay {
  display: block;
}

例5: 条件付き表示（複数のBool値の組み合わせ）

複数のBool値を組み合わせて、複雑な条件分岐を実現します。 AND条件やOR条件を表現できます。
/* 複数のBool値のAND条件 */
#condA:checked ~ #condB:checked ~ .result {
  /* 条件AとBが両方trueの時 */
}

/* 3つのBool値のAND条件 */
#condA:checked ~ #condB:checked ~ #condC:checked ~ .result {
  /* すべての条件がtrueの時 */
}
